# Aurelle Hair Studio – Salon Website Template

React + Vite static site. No backend, no database.

## Run
    npm install
    npm run dev

## Build (deploy `dist/` to Netlify / Vercel / GitHub Pages)
    npm run build

## Customize
- All text, prices, contact info, WhatsApp number and image URLs: `src/data/siteData.js`
- Colours and fonts: variables at the top of `src/styles/index.css`
- WhatsApp number format: country code + number, digits only (e.g. 919876543210)
- Replace the sample testimonials with real reviews before going live
